What this app does

Gita & Grit is a private content-publishing application. It generates original short vertical videos about Hindu mythology, folk tales and motivation, and uploads them to YouTube Shorts, Instagram Reels and Facebook Reels using the official platform APIs.

It publishes only to channels and Pages owned by the same person who authorises it. It does not provide any service to third parties, does not access other people's accounts, and does not collect data about any other person.

The application is operated by the channel owner and is not distributed publicly.

Content

Videos are original: illustrations are generated for each scene, narration is synthesised, and each mythological or scriptural reference is credited with its source in the published description.

Platforms

  • YouTube — via the YouTube Data API v3, upload scope only
  • Instagram — via the Instagram Graph API, content-publish scope only
  • Facebook — via the Facebook Graph API, Reels publish scope only
